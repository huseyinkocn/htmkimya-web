# HTM Silikon Kimya Tekstil — web sitesi

[htmkimya.com](https://www.htmkimya.com) için tek sayfalık statik site. Derleme adımı yok; Tailwind CSS, Font Awesome ve Google Fonts CDN'den yüklenir.

## Yayına alma

`index.html` dosyasını ve `images/` klasörünü cPanel'de `public_html` dizinine yükleyin. Yeni görselleri `index.html`'den önce yükleyin.

## Klasörler

- `images/anasayfa/` — ana sayfa görselleri
- `images/urunler/` — ürün kartı görselleri
- `images/galeri/` — ürün görseline tıklanınca açılan galeri
- `images/` — logo ve site ikonları
